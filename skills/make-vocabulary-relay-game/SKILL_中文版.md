# make-vocabulary-relay-game

## 目标

把教师提供的词表制作成一款节奏快、适合投影的课堂游戏，名称为“单词接力闯关”。它应当与普通配对卡牌和隐藏陷阱游戏明确区分：

- 配对只是进入答题的动作，而非全部玩法。
- 答对后让队伍在赛道上直观前进，并可形成连击。
- 答错会结束连击并产生短暂、明确的代价，不涉及隐藏信息。
- 游戏鼓励准确认读、词义回忆和团队策略，不要求学生输入文字。

## 适用场景

当教师希望创建、替换或更新双队英语课堂接力游戏中的词汇时使用本 Skill，尤其适合教师提供英文词、中文释义或两者兼有的情况。

不要将本 Skill 用于固定的 24 张卡、12 对配对棋盘；不要用于双方秘密布置陷阱的游戏；也不要用于个人课后练习。

## 必要信息

制作游戏前，只收集以下缺失的必要信息：

1. 词汇：英文单词和中文释义的配对。若教师只提供英文词，可补充恰当的中文翻译，并标注为“待教师确认”。
2. 学习者水平：未提供时默认小学或初中低年级。
3. 队伍数量：未提供时默认两队。

默认使用 12 至 24 对词汇。少于 12 对时，应先征得教师同意再补充复习词；多于 24 对时，应提供可选择的词表，或询问是否拆分为多轮。

## 游戏设计

### 核心循环

1. 教师开始一轮后，当前队伍获得一个醒目显示的英文单词。
2. 学生大声读出单词；读对后由教师点击或轻触该单词确认。
3. 该队从三张中文释义卡中选择一张。仅一张正确；干扰项来自同一份词表，应有一定辨识度，但不能造成歧义。
4. 配对正确时，队伍的赛道角色前进一格。连续答对两题后，队伍可以选择“冲刺”：再答一道更难的题，成功可额外前进一格。
5. 选择错误时，该队连击结束，系统短暂标记该词供之后复习，并轮到另一队。不得使用羞辱、生命值或永久淘汰。
6. 最先抵达终点的队伍获胜。若题目先用完，则赛道位置更靠前的队伍获胜；平局时用一道突然死亡题决胜。

### 学习保障

- 在词义选择可以计分前，必须由教师确认学生已完成大声认读。
- 已正确完成的词对，在全部词对都至少出现一次前不得重复出现。
- 将答错词放入可见的复习盘。结束后，允许教师只重玩这些词。
- 每次答对后，显示英文词、中文释义，以及可选的例句约两秒。
- 每次新开游戏时，随机排列单词和干扰项。

### 难度

提供三种模式：

- 热身：两项选择，无冲刺，赛道较短。
- 标准：三项选择，连续答对两题后可冲刺。
- 挑战：四项选择，连续答对两题后可冲刺，每队另有一道只考发音的题目。

默认使用“标准”模式。

## HTML 交付要求

创建单个、离线可运行、UTF-8 编码的 HTML 文件。不得依赖 CDN、外部字体、远程图片、网络连接、登录或构建工具。

页面必须包含：

- 教师设置面板，可输入或粘贴词对、选择模式、设置队名，以及开始或重置游戏。
- 适合投影的大型游戏画面，包含队伍颜色、轮次提示、赛道角色位置、终点线、进度、英文单词、选项卡、连击提示和复习盘。
- 教师操作控件：确认认读正确、选择释义卡、跳过、撤销上次计分、重玩错词、重置、全屏和声音开关。
- 键盘快捷键：空格确认认读；数字键 1 至 4 选择卡片；R 重置；F 切换全屏；U 撤销最近一次计分操作。
- 足够的色彩对比度、大型点击区域、除颜色外的文字提示，以及不依赖声音才能理解的关键信息。
- 设置面板内用不超过五行简短中文说明游戏规则。

视觉应有趣但不杂乱：以道路或地图体现进度，使用醒目的卡片、清晰的答对和纠错状态，以及不会延误下一轮的轻量动画。

## 实现指引

1. 支持解析以下粘贴格式：英文单词, 中文；英文单词 - 中文；英文单词：中文；或以制表符分隔的两列。将解析错误显示在对应行旁。
2. 仅用 localStorage 保存教师输入和偏好，并提供清除按钮。
3. 从未使用的释义中生成干扰项。禁止重复正确选项，且避免选项文字与题目完全相同。
4. 用小型、显式的 JavaScript 状态模型维护：词汇队列、已完成词对、错词、轮次、队伍进度、连击数、历史栈和设置。
5. 通过历史栈实现撤销，使其准确恢复之前的轮次、进度、连击、队列和复习盘。
6. 至少测试：12 对词、全部三种模式、两队和三队、一次答错、一次冲刺成功、一次冲刺失败、撤销、重玩错词、键盘操作、刷新后的数据保持和全屏。
7. 将完成的 HTML 保存到任务专用输出目录，使用清晰的中文文件名，例如“单词接力闯关_水果主题.html”，并用 send_file 交付。

## 边界

- 教师始终拥有认读是否正确的判定权；页面不得声称能够自动评估发音。
- 不得要求学生注册账号、记录学生姓名或传输词汇数据。
- 不得使用受版权保护的角色图像或外部加载的资源。
- 教师已提供译文时，不得在未告知的情况下自行替换。
